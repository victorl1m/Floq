# Orchestration skill inspiration

This skill's operating shape was informed by public examples on [skills.sh](https://www.skills.sh/):

- [hyperb1iss/hyperskills: orchestrate](https://www.skills.sh/hyperb1iss/hyperskills/orchestrate) emphasizes checking the host's actual delegation surface and keeping one coordinator responsible for integration.
- [deepgram/wsh: agent-orchestration](https://www.skills.sh/deepgram/wsh/agent-orchestration) separates workflow guidance from exact API/CLI syntax and warns against guessing unsupported commands.

Those are design inspirations only. Floq command names, flags, reachability, and behavior in `SKILL.md` come from Floq's own CLI and runtime implementation.
