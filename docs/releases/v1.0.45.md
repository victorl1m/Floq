# Release v1.0.45

## Fixes

- **"Floq Runtime: Installed 0.2.0 / latest 1.0.43" with an Update button that never goes away:** the runtime reported a hard-coded 0.2.0 when `FLOQ_RUNTIME_VERSION` was not set, so it always looked older than the latest release. It now reports its real release version from `runtime/package.json`, which is set to the app version on every release (a test fails if they drift).

## Tests

- Runtime version tests (2), admin updates and config tests; runtime build.

## Deployment

Runtime change: update the runtime once (the Update button, or redeploy). After that it shows the right version and only offers real updates.
