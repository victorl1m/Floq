# Release v1.0.14

## Features

- **Touchpad gestures on the canvas.** On a laptop touchpad, a two-finger swipe now pans the agent canvas and the memory graph instead of zooming. Pinch zooms smoothly around the cursor. A mouse wheel and Ctrl+wheel still zoom. Floq tells a touchpad from a mouse per scroll event. If it guesses wrong on your hardware, pick **Trackpad** or **Mouse** in Settings > Appearance > Canvas scroll (also in Ctrl+K). Terminals, the composer and lists inside nodes still scroll themselves.
- **Artifacts tab: search and day headers.** A search box filters artifacts by name or folder. Files are grouped under one header per day (Today, Yesterday, then by date) with a count. Headers always start collapsed. A search opens every day that has a match, and clearing it collapses them again.
- **Floq Artifacts is the default place for deliverables.** Claude agents no longer publish pages to claude.ai. A hook refuses publishing and tells the agent to save the file in the project's Artifacts folder and name it to you. Reading claude.ai links still works. Claude is told its scratchpad is for throwaway files only, and Codex the same about `/tmp`. (Runtime change, live since `3410156`.)

## Fixes

- **Memory store connection loop.** Since the `redis` 6 upgrade, an idle memory connection was dropped every 5 seconds, then reconnected and re-ran its setup, which spammed `memory.redis_error` in the logs. The client now sends a keepalive ping every 10 seconds, and only a store that stops answering for 30 seconds is dropped. (Runtime change, live since `1c98c1a`.)
- **Network namespaces.** The runtime container now gets `/dev/net/tun`, which `pasta` needs for per-user network namespaces. (Runtime change, `f6c4084`.)

## Tests

- `tsc --noEmit` and both runtime `tsc` configs clean.
- Unit tests: artifact grouping 3/3, wheel classifier 6/6, settings index 6/6, memory keepalive 3/3, artifact redirect 4/4.
- Playwright: Artifacts tab 7/7 and canvas wheel 5/5. Settings and canvas specs pass. The memory-graph timing specs (simulation cooldown, click-to-centre, node drag, zoom buttons) fail on unchanged `v1.0.13` code on the same machine too, so they are not caused by this release.

## Deployment

The runtime changes are already live from `main`. This release ships the app changes (touchpad gestures and the Artifacts tab) in a new Windows installer. This is a full release.
