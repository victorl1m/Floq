# Floq v0.6.29

## Changes

- **Memory graph.** The Memory screen (Brain button in the canvas titlebar) has a new Graph view next to the List view.
  - **Movement:** the graph is drawn on a canvas and keeps moving gently until it settles. Pan, zoom, pinch and Fit are smooth. Dragging a memory pulls the memories linked to it along.
  - **Hover:** hovering a memory highlights it and its direct links and fades everything else.
  - **Labels:** labels fade in as you zoom in. Selected and hovered memories are always labelled.
  - **Colors:** memories are colored by type with the app's theme colors, and pinned memories get a ring.
  - **Links:** each memory links to its 3 most similar memories, and an arrow points from an outdated memory to the one that replaced it. A slider sets how similar memories must be to be linked.
  - **Reduced motion:** with reduced motion on, the graph shows a still, settled layout.
- **Grouped view.** With more than about 40 memories, the graph opens grouped.
  - **Bubbles:** one bubble per group, labelled with its name and count (for example "Facts · 15").
  - **Grouping:** by Type, by Topic (clusters of similar memories) or by Author.
  - **Links between groups:** all links between two groups are merged into one line, which gets thicker with more links.
  - **Expanding:** clicking a group opens it in place, and its memories spring out of the bubble. Double-clicking zooms to the group. Expand all and Collapse all buttons are included.
  - **Search:** groups that contain matches light up, and they open when there are only a few matches.
- **Memory screen controls.** The Memory screen now uses the app's own toggle groups, checkboxes, dropdowns, empty and loading states, with Retry buttons when loading fails. The screen is solid over the translucent window background.

## Upgrade notes

- **Runtime:** redeploy the runtime to get the new graph endpoint (Dokploy deploys this automatically from `main`). On an older runtime, the app works out the links itself from the memory text.

## Verification

- **Typechecks:** the frontend and runtime typechecks pass.
- **Unit tests:** the runtime memory and graph tests pass (29/29), and the force-layout and grouping tests pass (22/22).
- **Playwright:** the memory screen suite passes all 42 tests, one test at a time. It covers the list, graph and grouped views, keyboard use, light and dark mode, and narrow windows. In headless Chromium with software rendering, the median work per frame with 300 memories is 0.4–2.8 ms, and the test requires under 16 ms.
