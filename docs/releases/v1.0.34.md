# Release v1.0.34

## Changes

- **Spinner instead of guessed placeholders.** Lists whose length is unknown (projects, skills, secrets, plugins, memory, artifacts, files, conversations, changes, repositories, task boards and automations) show the app's spinner with a short "Loading" label instead of skeleton rows that guess how many items will appear. Fixed-shape placeholders (a single value, a known form) stay.
- **Island:** sits 48 px from the top of the screen so browser tabs stay usable, and the "N waiting" pill shows three softly pulsing dots (like someone typing) instead of the green bars. Reduced motion keeps the dots still.
- **Usage-limit menu on agent cards** is simpler: "On usage limit: Keep going / Switch model only / Pause".

## Tests

- Frontend typecheck and vite build. Island position (Rust) not compiled here; Windows CI is the check.
