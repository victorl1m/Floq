# Release v1.0

## Features

- **Organizations.** Projects now belong to an organization. Every user gets a personal organization, requests carry `X-Floq-Organization`, switching organizations is a first-class flow, and agents can message across organizations.
- **WebDAV read-write.** Mounted WebDAV shares can be written to, and the workspace supports file creation plus copy and delete pinned to file descriptors.
- **Files tab.** Create files from the tab and preview docx, xlsx and pdf documents in the file dialog.
- **Artifacts.** Each project has an Artifacts folder and a matching tab in the right sidebar.
- **Agent limits.** Agent and subagent limits are configurable with hard ceilings, and only awake agents count toward them. The manager caps wake-ups.
- **Canvas.** Neutral marquee selection, the app window as a canvas node, and a Changes pill in the titlebar. The Tauri window minimum size is now 820x520.
- **Interface.** Acrylic active states, sticky headers, and an organization switcher with pixel dots.
- **Agents.** Robot avatars, cleaner card headers, role icons and labels, and a "Connect another provider" entry.

## Fixes

- **Mounted folders.** Opening a mounted item's folder now works in the platform file manager, with the item path validated segment by segment.

## Security

- Download links carry an audience claim.
- Workspace copy and delete operate on pinned descriptors, so a path cannot be swapped mid-operation.

## Tests

- Runtime tests for WebDAV write, workspace create, artifacts, agent ceilings, organization migration and lifecycle, and cross-organization messaging.
- Playwright specs for the files tab, previews, artifacts, canvas selection, the app window node, avatars, role picker, org switch and sidebar dots.

## Upgrade notes

- The database migration adds personal organizations. It runs on first start.
- WebDAV mounts are read-write. Review who can reach a share before upgrading.
- `xlsx` is installed from the SheetJS tarball (`https://cdn.sheetjs.com/xlsx-0.20.3/xlsx-0.20.3.tgz`), not from the npm registry.
- The minimum window size is 820x520.
- Switching organization resets the current view.

This is a pre-release.
