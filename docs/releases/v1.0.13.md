# Release v1.0.13

## Security

- **Cross-tenant credential theft (HIGH).** Root-side reads of files in agent homes followed symlinks and blocked on FIFOs, so one user's sandbox could plant a link and make the runtime read another tenant's credentials. Reads and writes in homes now go through descriptor-pinned helpers that refuse symlinks and FIFOs. Project delete uses the same pinned removal.
- **Plugin-promotion symlink (HIGH).** Promoting managed Claude plugins and writing Codex managed guidance and native titles could be steered through a symlink. These paths are now confined to the user's home.
- **Invitations can no longer create the instance admin.** The bootstrap-admin email is reserved: it cannot be invited and cannot register through an invitation. Wired-context writes are scoped to the owning user.
- **Browser and egress hardening.** Each agent gets its own browser token derived from the daemon token, which no longer leaves the runtime. The egress daemon applies its accept budget only after the peer check.
- **Per-user network namespaces are on by default.** `FLOQ_NETNS` unset now means `required`: the runtime refuses to start without them. Use `FLOQ_NETNS=off` only on trusted single-tenant hosts. See `runtime/README.md` for host requirements.

## Features

- **Notifications.** Agents can run `floq notify --title ... [--body ...] [--level ...] [--category ...] [--action-*]` to send a one-way notice that needs no answer. It is saved, shown as a toast and listed in the new Notification Center, which supports read, clear and action links. Design: `docs/design/notifications.md`.

## Tests

- `tsc --noEmit` and both runtime `tsc` configs clean.
- Runtime security and notification tests pass.
- Playwright: 231 passed, plus the known flaky specs.

## Deployment

Pushing to `main` redeploys the runtime. Operators on hosts without network namespace support must set `FLOQ_NETNS=off` before upgrading. Running agents need a session restart to pick up the new browser token and `floq notify`. This is a full release.
