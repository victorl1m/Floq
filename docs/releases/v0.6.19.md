# Floq v0.6.19

## Upgrade notes

Movidesk, Azure DevOps and WAHA are now installable plugins rather than bundled plugins. After upgrading the runtime, an administrator must install them from **Settings > Plugins > Browse plugins**. Existing plugin data is retained. Review configuration and enablement after reinstalling.

Plugin credentials now use a separate encrypted store, managed through **Settings > Plugins > Configure > Credentials**. Older vault credentials migrate automatically. A vault copy remains while its user's MCP configuration is unreadable or still references it; migration retries when that workspace becomes available. Plugin MCP servers requiring secret environment variables remain unsupported.

Rebuild and deploy the runtime image to enable the new CLI command and runtime behavior. Installing the desktop update alone does not update the server.

## Changes

- Move project canvas actions into the app titlebar, including tools, Wake all, Vault and New agent. Narrow layouts use a Canvas tools menu while Vault and New agent remain direct controls.
- Add optional `floq setup [--dry-run] [--agents]` to export Floq workflow guidance into repository instruction files. Preserve existing content and skip files already containing Floq guidance. Both dry-run flag orders are safe.
- Isolate plugin credentials from agent-accessible vault secrets, with write-only credential controls, migration retries and bounded audit retention.
- Support installing the external plugin packages through the existing plugin catalog and GitHub package flow.
- Push non-waiting CLI decision results back to the requesting terminal and improve peer reply guidance.
- Synchronize bundled and canonical Floq orchestration guidance.
