# Release v1.0.53

## WhatsApp

- **History import no longer fails with "invalid input syntax for type json".** A link preview cut at 300 characters could split an emoji, and Postgres refused that one message and stopped the import. Text is cleaned before it is stored, and a message the database still refuses is skipped instead of ending the import. Press Retry on the import bar to continue.
- **Images and files load by themselves.** History-imported media was treated as gone until Retry. It now downloads on first view, retries temporary WAHA errors, and shows "Not available here" only when WAHA says the file is gone.
- **Typing no longer lags:** only the message box re-renders while you type.
- **Sending:** the bubble appears at once with a clock, then gets its tick in place. A failed send stays as a bubble with Retry and Delete.
- **Chat list polish:** readable label tags on any theme, the row menu button fades in, the refresh icon turns smoothly, and the chat menu always opens at its button (it could jump to the top-left corner).
- **Voice notes:** smooth progress, and the play button lines up with the waveform.

## Island

- **Listen to voice notes from the notification card:** play/pause, seek, 1x/1.5x/2x, keeps playing when the card collapses, stops when dismissed. Generic: any plugin notification can carry audio, served only to its owner.

## Tests

- WhatsApp runtime tests 296/296; Playwright waha-full, waha-polish, waha-media, island-audio 69/69; frontend and runtime type checks clean.

## Deployment

Runtime and desktop change: redeploy the runtime (Dokploy does this on push); the desktop app updates itself.
