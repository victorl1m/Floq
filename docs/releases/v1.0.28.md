# Release v1.0.28

## Changes

- **Old automatic browser wires are removed.** Before v1.0.27 the canvas wired agents to Browser nodes by itself. Each project drops those wires once, the first time it is opened with this version.
- **Agents link browsers on purpose.** `floq browser list`, `floq browser link [NODE] [--agent ID]` and `floq browser unlink [--agent ID]` let an orchestrator or any agent wire itself, or another agent of its project such as a subagent, to a Browser node the user put on that project's canvas. Agents cannot create Browser nodes or reach another project's. Documented in the orchestrate skill.

## Tests

- Runtime build, frontend typecheck.

## Deployment

The desktop app updates itself. The agent command needs the runtime redeployed.
