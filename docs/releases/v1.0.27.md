# Release v1.0.27

## Fixes

- **Browser nodes are never opened or wired automatically.** The canvas used to wire every agent of a project that touched the shared browser to that project's first Browser node, and to open a Browser node when an agent connected, so a browser showed up linked to agents in projects where nobody added it. Browser nodes now appear only when you add one, and only you draw wires to them. Existing nodes and wires stay until you close or delete them; deleted ones do not come back.
