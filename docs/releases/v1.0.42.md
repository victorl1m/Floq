# Release v1.0.42

## Fixes

- **`browser.mcp_sync_failed` on wake:** when the runtime refreshes the browser MCP entry in agents' configs, a Codex session folder that disappeared between reading and writing (the session ended or was cleaned up) now counts as nothing to update instead of a failure. Any other failure now names its error code, e.g. "Could not safely update the MCP config (EACCES).", so the log says what went wrong.
