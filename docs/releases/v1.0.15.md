# Release v1.0.15

## Security

- **Tenant namespaces no longer reach the host's public addresses.** Through pasta a tenant could connect to the host's own public IP and reach every service published on it (other projects' databases, SSH, a deploy panel). The namespace firewall now drops the host's public egress addresses, discovered through a short, time-limited IP echo or set with `FLOQ_HOST_PUBLIC_IPS`.
- **The runtime container's loopback is no longer mirrored into namespaces.** pasta runs with `-T none -U none`, so a tenant cannot reach ports listening on the runtime's loopback.
- **Root file operations in agent homes are descriptor-pinned.** Writes the runtime makes into a user's home go through fd-based helpers that refuse symlinked path segments and never follow planted links.
- **Chromium sandbox policy.** `FLOQ_BROWSER_SANDBOX=required` makes the agent browser refuse to start without Chromium's own sandbox. The default `auto` falls back to `--no-sandbox` with a logged warning. A shipped AppArmor profile (`runtime/apparmor/floq-runtime`) allows user namespaces on hosts that restrict them.

## Features

- **mkcert and certutil for HTTPS dev servers.** `next dev --experimental-https` and similar tools work in agent sandboxes. Each user gets a CA in their own encrypted home, trusted only in their own NSS database.
- **Auto-approve notice.** A first-run dialog explains that auto-approve is on and how to turn it off.
- **Optional SignPath code signing** for the Windows installer in CI (see `docs/code-signing.md`).

## Fixes

- **Browser node wires connected agents.** The Browser node now opens and links agents that connect to the browser automatically, so you can watch them without adding the node by hand.
- **`floq wired`, `floq sticky` and `floq help`** are allowed inside agent sandboxes.
- **Browser tests** are less timing-sensitive (credit accounting, pinned source port, temp directory cleanup).

## Tests

- `tsc --noEmit` and both runtime `tsc` configs clean.
- Runtime tests run file by file: all pass except `handoff`, `portRequests`, `projectGrouping` and `terminalSplit`, which already failed before this release.
- Playwright: 240 pass. The memory-graph timing specs also fail on the previous release's code.

## Deployment

Runtime and app both change.

1. **AppArmor (host, once).** Load the profile with `apparmor_parser -r runtime/apparmor/floq-runtime` (copy it to `/etc/apparmor.d/` first), then set `FLOQ_APPARMOR_PROFILE=floq-runtime` and recreate the stack. Once `floq browser status` shows `chromium sandbox on`, set `FLOQ_BROWSER_SANDBOX=required`.
2. **Optional:** set `FLOQ_HOST_PUBLIC_IPS` (comma-separated) if the host's public address cannot be discovered automatically.
3. **Code signing:** follow `docs/code-signing.md` to set up SignPath. Without it the installer stays unsigned.
4. **Agents** pick up mkcert and the NSS database the next time they wake.
5. **App:** update the app and reload the canvas to get the Browser node fix.
