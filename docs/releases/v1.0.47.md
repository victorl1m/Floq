# Release v1.0.47

## Fixes

- **Agents stayed paused after a usage reset:** when Claude hit a usage limit, Floq parked the agent and only looked again at the reset time the limit reported. A limit cleared early (usage reset, extra usage, plan change) was ignored until then. Floq now checks real usage every few minutes while an agent is parked and resumes it as soon as there is room.
- **Messages queued behind Claude Code's own limit wait:** Claude Code shows "Usage limit reached · continuing automatically at <time> · esc to cancel" and ignores typed input until that time, even after the limit is cleared. Floq now sends Esc before typing a message into a session in that wait, and types a short "continue" into a parked agent that is still running when its limit clears.

## Tests

- Fallback (71), limit wait (3), runtime version (2); runtime build.

## Deployment

Runtime change: update the runtime (Settings > Updates or redeploy). Sessions already sitting in Claude Code's wait continue after the runtime restarts.
