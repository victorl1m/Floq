# Release v1.0.35

## Changes

- **Usage-limit settings, simpler:** "Keep agents working", three short steps (Smaller Claude model, Another Claude account, Codex) with one-line hints, and "Switch back after the reset". The steps show only while the main switch is on.
- **Account menu:** no longer shows the active organization under your role.
- **Organization avatars:** built on the shadcn Avatar; without an image they show the initials on a gradient picked from the organization name (same name, same colours), using the theme's own colours.
- **Table headers:** no filled background; they sit on the card material with a line under them, everywhere.
- **No more system form controls:** Desktop settings use the standard switches; organization member, invitation and owner pickers use the app's dropdown; the worktree delete dialog uses the app's checkbox.

## Tests

- Frontend typecheck, vite build, unit tests: organization icon (4), settings index (6), project tasks (10).
