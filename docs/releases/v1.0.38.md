# Release v1.0.38

## Browser

- **Automation flag hidden for your own logins.** Chromium starts with `--disable-blink-features=AutomationControlled` (and never `--enable-automation`), so `navigator.webdriver` is false. This replaces the earlier "no stealth" rule, by decision, together with the lock below.
- **"Take control" lock.** A toggle on the Browser node, and any click or key you send into the page, give you control. While you hold it, agents cannot navigate, click, type or run scripts on that page; they get "The user is controlling this browser; wait and retry" (screenshots and page snapshots still work). A "You have control" badge shows on the node. Released by the toggle, after 60 s without your input, or when the node closes. Enforced in the browser daemon, not only in the app.
- **Delete removes a selected Browser node** (and its wires), like other nodes.

## Updates

- **What's new:** the "Floq X is ready" notice opens that version's changelog inside the app, with Restart now, Later and Open on GitHub.

## Tests

- Runtime build, root typecheck, browser daemon tests (39 pass; 4 real-Chromium tests fail the same way before this change). Measured: navigator.webdriver true -> false with the flag.
- Not tested: the lock end to end in a running app.

## Deployment

The flag and lock are in the runtime image: redeploy the runtime (running browsers pick them up on their next start).
