# Release v1.0.58

## Fixes

- **Agents no longer pause for a usage limit they did not reach.** When a paused agent woke, Claude Code redrew its earlier "You've hit your limit · resets 3:50pm" line; Floq read it as a new limit (with tomorrow's time) and parked the agent again or moved it to another account. A limit seen in the terminal now counts only when the account's usage confirms it, or, with usage unknown, when a 5-hour reset is within 5 hours.
- **No more native webview menu (Back, Refresh, Save as, Print).** Right-click or long-press on a WhatsApp chat opens its chat menu at the pointer; text fields and selected text keep copy and paste.
- **Footer Network indicator** is a dot and plain text aligned with the other footer items.

## WhatsApp

- **Deleted and edited messages are kept recoverable** (original text, caption and cached media stay stored with the time of deletion; every edit version is kept) and **stickers are parsed fully**. The screens that show them come in the next release.

## Tests

- fallback 74/74 (new: redrawn banner on wake, stale-banner rules); WhatsApp runtime 312/312; native-menu and network-footer Playwright specs; frontend and runtime type checks.

## Deployment

Runtime and desktop change: Dokploy redeploys the runtime on push; the desktop app updates itself.
