# Release v1.0.9

## Fixes

- **Cross-origin iframes load in the agent browser.** The browser daemon left every out-of-process iframe (embeds, payment frames, Cloudflare's Turnstile widget) paused and blank: it auto-attached them but never resumed them. Verification pages therefore showed no checkbox and clicks did nothing. They now load, show in the Browser node and receive clicks. Verified with Cloudflare's official Turnstile test keys: the always-pass key returns a token, and the forced-interactive key shows "Verify you are human", which a click from the node completes.
- **Clearer notice when a site blocks automation.** If a challenge page is still up after 15 seconds, the Browser node says the site is blocking automated browsers and suggests opening it in your own browser or using the site's API or a connector. Whether a real site offers an interactive challenge is up to that site; Floq adds no stealth.

## Tests

- New real-Chromium daemon test with a cross-origin iframe (fails without the fix); browser daemon tests 25/25, Browser node Playwright 12/12.
- `tsc --noEmit` and runtime `tsc` (both configs) clean.

## Deployment

Pushing to `main` redeploys the runtime (browser daemon change). This is a pre-release.
