# Release v1.0.18

## Fixes

- **Spec Kit works for every agent.** OpenCode and Antigravity agents no longer fail with "Spec Kit is only available for Claude and Codex agents". Floq now runs `specify init --integration <claude|codex|opencode|agy> --non-interactive`; the installed Spec Kit CLI had dropped `--ai`, so Spec Kit setup was silently failing for Claude and Codex too.
- **No agent starts on a provider you are not signed in to.** Creating, waking, resuming, recruiting and switching an agent (including the usage fallback's Codex step) now refuse a provider without a login, with "Codex is not connected for this account. Sign in to Codex in Settings › Providers". OpenCode is not gated (it has no reliable login signal).
- **Touchpad gestures over terminals.** A pan that slides over a terminal's input or a note keeps panning; a gesture over an input that cannot scroll pans the canvas; pinch zooms the canvas everywhere (terminals, browser node, panels) and never zooms the app window. An interactive terminal and the browser node keep their own scrolling.
- **Ctrl/Cmd+A, C, X, Z, Y in the Browser node** now act in the page (they were dropped by Chromium).
- **New-agent dialog:** the Role picker is hidden when "Create as orchestrator" is on.
- Runtime (since v1.0.17): terminals stay responsive when agents saturate CPU and memory; the network namespace is kept when a shard cannot be unmounted, and the lock is retried; `FLOQ_NETNS_ALLOW` is passed through docker-compose; the image build reads `opencode --help` from stderr.

## Features

- **Copy copies the file.** In the file and artifact viewer, Copy puts a text file's contents on the clipboard (markdown, JSON, HTML, CSV and code included); binaries still copy the path.
- **Save where you want.** Download in the desktop app opens the system save dialog (starting in Downloads) and then shows the saved file in its folder.
- **Play and preview more files.** Audio (mp3, wav, ogg, m4a, aac, flac, opus) and video (mp4, webm, mov, m4v, ogv) players; tsv and ods sheets; rendered Markdown with a Raw toggle; formatted JSON; HTML in a fully sandboxed frame; bmp, avif and ico images.
- **Formats the webview cannot play are converted.** wmv, avi, mkv, flv, mpg, 3gp, m2ts, wma, aiff, ac3, amr, and HEVC/ProRes mp4/mov are converted by the runtime with ffmpeg while streaming (H.264/AAC fragmented MP4; stream copy when already web-safe). ffmpeg reads the already-opened file, has no network or playlist access, runs niced as your user, at most 2 per user, and stops when the viewer closes.
- **Notifications:** category and project filters now sit behind one Filter button with a dropdown and an active-filter count.
- **Port forwarding:** forwarded rows show a chevron icon instead of a text arrow.
- **CLI:** `floq subagent recruit --task-file PATH` and `floq subagent ask ID --file PATH` send a file's text (subagents cannot read their parent's scratchpad).

## Notes

- Seeking inside a converted (ffmpeg) stream is not wired in the player yet.
- Not verified in a real app/OS yet: the save dialog and reveal-in-folder on each OS, audio/video playback per webview, the sandboxed HTML preview under the app's CSP, the ffmpeg run-as-user path on a live shard, and the Ctrl+A fix against a live page.

## Tests

- `tsc --noEmit` clean for the app, the runtime and the runtime image code.
- Runtime: new `specKit`, `providerGuard` and `transcode` tests (14 pass).
- App unit tests: `wheel-gesture` and `file-kinds` (13 pass).
- Not run in the sandbox: Playwright (`notifications` spec updated for the new Filter menu), `cargo check` (missing GTK system libraries; Windows CI is the Rust compile check).

## Deployment

Runtime and app release: rebuild and redeploy the runtime image (it now installs `ffmpeg`), then install the new Windows build (it adds `tauri-plugin-dialog`).
