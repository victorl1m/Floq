# Release v1.0.3

## UI

- **Home columns no longer overlap.** The recent agents and projects columns now have a min-width fix, so long titles truncate instead of running into the neighbouring column. Five new layout tests cover widths from 560 to 1600px.
- **Titlebar.** The toolbar (Changes and tools) is centred on the window, and the project name (mark, name, muted branch) is back on the left.

## Tests

- `tsc --noEmit` clean and the production build succeeds.
- Playwright: Home and Changes dialog specs pass, including the 5 new Home layout tests.

This is a pre-release.
