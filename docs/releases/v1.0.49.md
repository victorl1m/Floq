# Release v1.0.49

## Fixes

- **`browser.mcp_sync_failed` with no reason:** right after a user's home wakes, the browser's MCP entry sync could fail before the sandbox helper reported anything, and the log only said "Could not safely update the MCP config." The sync on wake and on the browser toggle now retries after 5 s and 30 s before logging once, and every helper failure names a reason (the helper's error code, CHECKSUM, NO_OUTPUT, EXIT_<n> or BAD_OUTPUT).

## Tests

- MCP config helper reasons, browser service retry, MCP install (with the node-pty stub in this sandbox); runtime build.

## Deployment

Runtime change: update the runtime. Desktop app updates itself.
