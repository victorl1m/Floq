# Release v1.0.16

## Features

- **Notifications on the island.** Notifications from `floq notify` now appear on the island instead of an in-app toast, so you see them on any screen and while Floq is in the background. Approvals and decisions still come first. Info and success leave the island after about 6 seconds and stay in the Notification Center; warnings and errors stay until you dismiss them. Clicking one brings Floq to the front and runs its action. The toast is kept only where there is no island (the web build).
- **The island follows you across monitors.** It opens on the monitor with your mouse cursor (then the monitor of the window in front, then the primary one). A full-screen app now hides the island only when it is on that same monitor.

## Fixes

- **Notification Center filters.** The category and project filters use the app's styled dropdown instead of the native one.

## Tests

- `tsc --noEmit` clean.
- Playwright: island, island motion, island notifications and notifications specs pass (32 + 10), plus 4 unit tests for the island contract.
- The monitor chooser and per-monitor suppression are pure Rust helpers tested on their own. The Windows-specific parts (monitor lookup, foreground window, focus on open) need a check on a real multi-monitor Windows desktop.

## Deployment

App-only release: install the new Windows build. The runtime is unchanged.
