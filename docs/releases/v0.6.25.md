# Floq v0.6.25

## Fixes

- **Island:** fixes the island disappearing when you hover it and move the mouse away.
  - **The cause:** the native hover monitor had been switched off since v0.6.13, so nothing could collapse or re-show the island if the page missed a mouse event. On top of that, any change to the island window's settings made the window layer hide it silently, and a render error left an empty, invisible window.
  - **The fix:** the hover monitor runs again and collapses the island from the real cursor position, re-shows it if something hides it, and never hides it while you hover or interact with it. A render error is logged and the island restarts itself.
  - **Full-screen detection:** a maximized window no longer counts as a full-screen app, so the island is not suppressed when your taskbar auto-hides.
  - **Smoother growth:** the island no longer resizes twice in a row when its content settles.
  - **Diagnostics:** the island now writes mouse enter and leave, visibility changes and errors to `island.log`, so a future report shows where it broke.
- **Tests:** adds Playwright tests for the island (`npm run test:e2e`).

This is a pre-release.
