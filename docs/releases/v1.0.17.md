# Release v1.0.17

## Features

- **OpenCode agents.** OpenCode (`opencode-ai` 1.19.5) is a new agent provider next to Claude Code and Codex. Each session gets a private OpenCode config, Floq's instructions and subagent policy ride in on every start and resume, and OpenCode's own `task` subagents are turned off. Sessions resume their exact conversation. Sign-in is by API key from the vault (`OPENROUTER_API_KEY` or `OPENCODE_API_KEY`).
- **Antigravity agents.** Google's Antigravity CLI (`agy` 1.5.9) is a new agent provider. Sign in with your **Google account** (Settings › Accounts › Sign in with Google: open the link, paste the code back) or use a `GEMINI_API_KEY` from the vault. The Google login is shared by all your Antigravity agents and preferred over the key; an expired login falls back to the key on the next start. Floq skips the CLI's first-run colour picker, and Antigravity agents started together in one folder never mix up their conversations.
- **Antigravity swarms on the canvas.** Antigravity's native swarm stays on. Every swarm worker and Antigravity subagent appears on the canvas under its host, styled like a Floq agent, with its status (working, waiting, done, killed, error, stopped), current activity and a short transcript. Messages to a worker are relayed through the host agent. Killed workers can be hidden.
- **Recruit the new providers.** `floq subagent recruit --provider opencode|antigravity` works, each provider has its own auto-approve setting (on by default, covered by the first-time warning), and both appear in the new-agent dialog with their own models and icons.

## Notes

- Usage fallback, provider switching, Floq's skills and MCP management, and spec-kit stay Claude/Codex only.
- Swarm workers are full agents on your Google account or Gemini key; Floq's per-agent cost and limits don't count them.
- Vault names starting with `ANTHROPIC_`, `OPENAI_`, `OPENCODE_` config/permission names and `AGY_` stay reserved.
- Not yet verified with a live account: the Antigravity Google token format, the swarm's on-disk layout during a real `/swarm`, and Antigravity's own subagents being visible after resume.

## Tests

- `tsc --noEmit` clean for the app and the runtime.
- Runtime: new `cliProviders`, `cliCapture`, `agySwarmMirror` and `agyLogin` tests (fake `agy`, hostile SQLite databases, concurrent starts) plus the existing provider, subagent, vault and restart suites.
- Playwright: `virtual-agents` and `agy-login` specs.

## Deployment

Runtime and app release: rebuild and redeploy the runtime image (it now installs `opencode-ai@1.19.5` and the sha512-pinned `agy` 1.5.9), then install the new Windows build.
