# Floq v0.6.27

## Runtime

- **Prompt cache settings:** three new server variables control Claude Code's prompt cache for every session.
  - `FLOQ_CACHE_TTL` (`auto`, `5m`, `1h`): the main conversation's cache lifetime. `auto`, the default, writes nothing and lets Claude Code choose (1 hour on a subscription, 5 minutes on an API key).
  - `FLOQ_CACHE_HELPER_TTL`: the same for small helper calls.
  - `FLOQ_CACHE_DISABLE=1`: turns the prompt cache off for Claude sessions, for debugging only. A vault secret cannot undo it.
  - Floq never overwrites a value the user set in their own Claude settings; it records what it wrote and only changes its own values.
  - The three variables are now passed through `docker-compose.yml` and documented in `runtime/README.md` under "Prompt cache".
- **Cache-stable prompts:** new tests make sure the system prompt blocks and the wired context are byte-identical across calls, so the cache keeps hitting.

This is a pre-release.
