# Release v1.0.54

## Fixes

- **Downloads work again in Files and Artifacts.** The desktop app registered `download_with_picker` but did not allow it for the main window, so Download failed with "Command download_with_picker not allowed by ACL". A unit test now fails when any registered desktop command is not allowed.
- **Enter on "Wake and send" wakes the agent and sends.** The confirm focused Cancel, so Enter cancelled. Escape still cancels; destructive confirms keep Cancel as the default.
