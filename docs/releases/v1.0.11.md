# Release v1.0.11

## Fixes

- **"Route browser traffic through this computer" works in the desktop app.** Turning it on failed with "Command egress_start not allowed by ACL": the egress commands were registered in the app but missing from the main window's permission set. `egress_start`, `egress_stop` and `egress_status` are now allowed.
- **Pasting an image from the system clipboard works in the desktop app.** The native image fallback (`read_dropped_image`) was missing from the same permission set, so it was refused silently.

## Settings

- **New Settings > Browser section.** The agent browser switch, Restart, Import cookies & data, Clear browser data and "Route browser traffic through this computer" moved out of Agents into their own section. The canvas Browser node opens it directly.
- **The usage fallback chain moved to LLM Providers**, next to the Claude accounts. The fallback toast points there.
- The egress options use the app's standard radio group and select.

## Tests

- `tsc --noEmit` clean, `cargo check` clean.
- Playwright: settings sections, browser egress and fallback specs 21/21.

## Deployment

Pushing to `main` redeploys the runtime. This is a full release.
