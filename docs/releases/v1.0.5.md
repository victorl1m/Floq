# Release v1.0.5

## Fixes

- **Artifacts downloads work in the desktop app.** Downloading a file from the right sidebar's Artifacts tab failed with "Invalid download URL": the desktop downloader only accepted workspace file links (`/v1/sessions/<id>/files/download`). It now also accepts the Artifacts route (`/v1/sessions/<id>/artifacts/download`), with the same signed one-time token and same-origin, no-redirect rules.
- **Team switcher.** The line under the organization name shows only your role; the organization count is gone.

## Tests

- New Rust tests for the download link check (workspace and Artifacts links accepted; other routes, missing token and extra query parameters refused).
- `tsc --noEmit` clean and the production build succeeds.

This is a pre-release.
