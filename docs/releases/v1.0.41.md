# Release v1.0.41

## Fixes

- **No more pasta errors at startup.** With v1.0.39 the PID-file error was gone, which showed the real limit: pasta dropped to the `nobody` user is not allowed to join the network namespace the runtime (root) created ("Couldn't switch to pasta namespaces: Operation not permitted"). The probe failed six times and then fell back to root, which is what worked all along. pasta now starts as root directly (it still sandboxes itself); `FLOQ_NETNS_PASTA_UID` can still choose another uid.
