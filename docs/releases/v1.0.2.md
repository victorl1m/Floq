# Release v1.0.2

## UI

- **Home redesign.** Home is now a calm start screen: a short greeting, a hero composer with attachments, a keyboard hint row, quick-start chips, and card lists of recent agents and projects. The animated matrix backdrop is gone, replaced by a static dot grid and a soft glow.
- **New avatars.** Agents get a Floq avatar: a flat blob with two white eyes, drawn locally as inline SVG from the session id. The same session always gets the same avatar. DiceBear was removed, so there are no avatar dependencies or network requests.
- **Sidebar polish.**
  - Project folders carry no fill and only the selected project gets a subtle wash.
  - The header dots sit on the top strip of the sidebar panel.
  - The account name and card follow the new layout.
- **Cleaner agent card.** The state badge is replaced by a tooltip on the avatar, and only Failed shows a visible label. The message input is transparent and keeps a focus ring for keyboard users.
- **Titlebar.** The project identity (mark, name, muted branch) is centred on the window. Changes is its own button in the right cluster.

## Tests

- `tsc --noEmit` clean and the production build succeeds.
- Playwright: 120 of 120 pass, including new specs for Home (`e2e/home.spec.ts`), sidebar row states and the updated avatar and Changes dialog specs.
- Unit tests: 30 of 30 pass.

This is a pre-release.
