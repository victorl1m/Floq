# Floq v0.6.26

## Fixes

- **Island:** redesigns the hover animation and fixes the flicker when you unhover and hover again.
  - **The cause:** the capsule's expand/collapse used two animations that fought each other, so hovering again while it was collapsing showed the collapsed pill and the expanded card at the same time. Hovering again mid-collapse could also leave the capsule closed while the window was open.
  - **The fix:** the motion is now a single set of reversible transitions. The pill fades out as the capsule opens and the card fades in; collapsing reverses it. Hovering again while it closes reopens from where it is, with no jump. A native collapse can no longer close the island while the pointer is over it.
  - **A collapse bug found in testing:** every collapse threw an error in v0.6.25 (the layout timer was called incorrectly), which could blank or reset the island. This is the likely reason it still disappeared after hover.
- **Tests:** the island is now tested in a real browser frame by frame (`e2e/run-local.sh`, 12 Playwright tests plus the layout unit tests).

This is a pre-release.
