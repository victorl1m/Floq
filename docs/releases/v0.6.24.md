# Floq v0.6.24

## Fixes

- **Island:** fixes the island disappearing on hover and leaving the top of the screen unclickable in v0.6.23.
  - **The cause:** v0.6.23's recovery watchdog reloaded or recreated a healthy island when the island didn't report its layout after being shown. That blanked it and left an invisible window over the top of the screen.
  - **The fix:** the watchdog now only writes "show without layout ack" to `island.log` and never reloads or recreates the window.
  - **Kept from v0.6.23:** the island is still not throttled while hidden, which is the fix for the island freezing after the computer sleeps.
- **Tasks:** the Tasks page has a solid background, so the desktop wallpaper no longer shows through the translucent window.

This is a pre-release.
