# Release v1.0.12

## Fixes

- **Pages load after a browser restart when traffic is routed through your computer.** After the agent browser restarted, pages sent through "Route browser traffic through this computer" failed to load. They now go through your connection again, and the agents' browser tool survives restarts.
- **Browser nodes belong to the project they were created on.** Each project lists only its own Browser nodes, and linking an agent to a Browser node from another project is refused.
- **Pasting text into an empty agent message bar no longer reaches the terminal.**

## UI

- **Ctrl+K searches Settings.** The search trigger now shows a normal pointer.
- **Dialogs and the Home composer use lighter shadows.** Dialogs drop the large elevation shadow and keep the rim; the Home composer drops the wide halo.

## Tests

- `tsc --noEmit` clean; `npm run build` and both runtime `tsc` configs clean.
- Runtime browser, egress, links and manager hook tests 132/132 (PGlite, real Chromium).
- Rust `cargo test --lib` 54/54.
- E2E unit tests 51/51.
- Playwright 217 passed, 5 failed, all in the memory-screen graph view (one perf test, known baseline). Rerunning that spec alone passed 40 and failed 2: the 300-memory grouped perf test and the zoom/pan/pinch test. This release changes no memory-screen files.

## Deployment

Pushing to `main` redeploys the runtime, which the egress fix requires. Running agents need a session restart to pick up the new MCP forwarder. This is a full release.
