# Release v1.0.57

## Fixes

- **Fallback switches Claude accounts again.** A reserve account whose usage could not be read (the usage endpoint frequently answers 429) was treated as unusable, parking agents while a free account sat idle. Unknown usage now tries the reserve (a blocked reserve reports its own limit and the chain moves on), failed usage reads serve the last known value with a 5-minute backoff, and the "Another Claude account" fallback step is on by default.
- **Claude accounts are an ordered list; any account can be removed.** Every connected login is used in order (first is active, the rest are the fallback chain). Settings now uses arrows to reorder and a trash icon to remove any account (including the primary or active one, promoting the next or signing Claude out if it was the last), replacing "Make active" and the Active badge.
- **Re-signing into an existing account renews it.** Signing in to a listed account refreshes its credentials instead of failing with "This account is already connected", and logins are keyed by account and organization so a personal Max plan and a Team seat on the same email coexist as two accounts.
