# Release v1.0.23

## Fixes

- **Every GitHub branch shows up in the branch switcher.** Floq imports projects with a shallow clone (`git clone --depth 50`), which is single-branch: the remote only fetched the default branch, so other branches (e.g. `homologacao/maria-enesa-ia-generativa`) never appeared, even with v1.0.22's fetch, and could not be tracked. The switcher's fetch now turns a single-branch remote back into a normal one (`git remote set-branches <remote> '*'`, the standard fix; custom refspecs are left alone), keeps shallow repos shallow, and new imports clone with `--no-single-branch`. Switching to a remote branch then creates a local branch tracking it.

## Tests

- Runtime: projectBranches + projectBranchesRemote 15 pass (new: a single-branch shallow clone gets every remote branch and can switch to one).

## Deployment

Runtime release: rebuild and redeploy the runtime image (the fix runs server-side). The desktop app updates itself.
