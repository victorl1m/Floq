# Release v1.0.50

## New

- **Uninstall plugins from Settings > Plugins.** Every installed plugin's row has an Uninstall button (administrators). You type the plugin id to confirm; its data and credentials are kept unless you tick "Also delete its data and credentials". Bundled plugins have no Uninstall. Before, uninstall was only reachable inside Browse plugins, and deprecated plugins (hidden from Browse) could not be removed at all.

## Tests

- Playwright: uninstall from the row (installed only, typed id, keep data / delete data), plugin row update icon; frontend typecheck.

## Deployment

Desktop app updates itself. No runtime change.
