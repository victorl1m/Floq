# Release v1.0.33

## Fixes (Tasks & Automations)

- The shortcut key on primary buttons (the "N" on New automation) was unreadable in dark mode; keys inside filled buttons now use the button's own colours.
- The quick-add input no longer draws a second focus border inside the composer.
- The project picker in quick add, and the status, priority, assignee, project, repeat-unit and "Ends" pickers, now use the app's own dropdown instead of the system one.

## Tests

- Frontend typecheck, vite build, project-tasks unit tests (10).
