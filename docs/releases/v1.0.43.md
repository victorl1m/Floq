# Release v1.0.43

## New

- **Organization icons:** organizations without an uploaded image get a generated "signboard" icon: a deep colour and a quiet geometric pattern picked from the organization id, with a large bold white letter. Readable from 16 to 64 px in light and dark. Used in the sidebar switcher, settings and invitations; an uploaded image still comes first.

## Fixes

- **Storage Sense "No report yet":** the first automatic run now happens 20 s after the runtime starts and it re-checks every 5 minutes, so a freshly deployed or woken workspace gets a report quickly. A run that removed nothing shows "Last run <time>: nothing to remove".
- Unit tests that load the runtime client (`org-error`) work again.

## Tests

- Org icon unit tests (9), org error unit tests (3), Storage Sense tests (24), frontend typecheck and production build, runtime build.

## Deployment

Desktop app updates itself. The Storage Sense fix needs a runtime redeploy.
