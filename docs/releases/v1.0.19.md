# Release v1.0.19

## Fixes

- **Agents continue by themselves when Claude hits a usage limit.** Mid-conversation limits used to leave the agent waiting for hours ("Usage limit reached · continuing automatically at …") until you restarted the terminal. Floq now recognises every limit kind (5-hour and weekly windows, Opus/Sonnet weekly, the org monthly spend limit, exhausted extra usage), including the CLI's own terminal banner, restarts the agent on the next usable fallback step right away and sends it an automatic "continue the task" turn.
- **The fallback chain keeps walking.** After one account switch Floq now tries your other accounts one by one instead of giving up; an account at 98 % or with an exhausted spend cap is skipped. Restarting an agent that is already on a fallback also moves on to the next usable step. Loop protection is unchanged.
- **Agent header:** the Fallback badge lines up with the role badges.

## Tests

- Runtime: `fallback` (6 new cases), `transcode`, `specKit`, `providerGuard` — 83 pass.
- `tsc --noEmit` clean for the app and the runtime.

## Deployment

Runtime and app release: rebuild and redeploy the runtime image, then install the new Windows build.
