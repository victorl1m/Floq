# Release v1.0.56

## WhatsApp

- **Group messages in the island read as the group's.** The card and the collapsed pill are titled with the group, the line above says "Group", and the sender leads the text ("Márcia: Bom dia!").
- **Saved contact names first.** Notifications and a group's last-sender preview use the name you saved for the contact, then the name the person set on WhatsApp, then the number.
- **Attachment tray:** a file card's remove button is a corner badge and no longer covers the file name.

## Browser

- **No more white screen in a Browser node.** All pages were tabs of one window and the browser paints only the front tab, so a node went blank whenever another tab opened next to it. Every page now gets its own window, and a watchdog restarts the live view if no frame arrives for 2 s.
- **Right-click menu on the Browser node:** back, forward, reload, copy address, open in your browser, open in a new node, duplicate, copy screenshot, zoom, take or give back control, link or unlink an agent, close.

## App

- **Footer "Ports" is now "Network".** It shows a live "Using your connection · N" indicator; its popover has the details, Stop and Use buttons, and the forwarded ports.
- **The "using your connection" notice is a short toast at the top** instead of a pill floating over the content.
- **Markdown previews render tables** (and strikethrough) in Files and Artifacts.

## Tests

- WhatsApp runtime tests 298/298; browser daemon tests (3 new, real Chromium); Playwright network-footer, browser-menu, waha-composer, md-preview; markdown and ACL unit tests; frontend and runtime type checks.

## Deployment

Runtime and desktop change: Dokploy redeploys the runtime on push; the desktop app updates itself.
