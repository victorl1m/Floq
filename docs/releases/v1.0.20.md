# Release v1.0.20

## Conversations survive restarts

Agent conversations are no longer lost when the runtime restarts, a resume fails or the encrypted home mount dies. Design and evidence: `conversation-autosave-design.md` (Floq Artifacts).

- **Resume never destroys a conversation.** A resume that fails right after start is classified (not found, id in use, transient). Transient failures retry after 2 s, 10 s and 30 s, re-waking the home and refreshing the login first. Floq no longer wipes Codex/OpenCode/Antigravity conversation ids or relaunches Claude with a colliding id. If it still fails, the agent card says "Couldn't resume, conversation kept" with Retry.
- **Boot resumes retry.** An agent whose resume was skipped after a restart (login refresh, home not ready) is retried after 30 s and 2 min; if that fails it is paused with "conversation kept".
- **Conversation history and reversible Start fresh.** Each agent keeps every conversation it ever had (`agent_conversations`). The card's history menu switches back to any of them; Start fresh opens a new conversation (Claude gets a new id) and keeps the old one.
- **Start fresh with summary.** When a conversation is truly gone, the notice and the history menu offer a fresh start seeded with a summary built from the saved transcript (goals, recent actions, last reply; no model call; obvious secrets redacted). Claude and Codex.
- **Last-good checkpoints.** Claude and Codex transcripts are copied append-only into `~/.floq/checkpoints/` inside the encrypted home (at most once a minute and on sleep) and restored automatically when the provider's own file is missing or truncated. Checkpoints of deleted agents are swept after 7 days.
- **Dead mount watchdog.** gocryptfs runs with `oom_score_adj -900`. Awake homes are probed every 5 s in a child process with a hard timeout (a hung mount can never block the runtime). A dead or hung mount is remounted and the user's running agents restart on the same conversation, with a warning notification; at most 3 recoveries per user per hour.
- **Claude never deletes transcripts.** `cleanupPeriodDays` is enforced very high, so Claude Code's 30-day cleanup no longer removes old conversations.

## Fixes

- **Browser nodes stay in their project.** A Browser node auto-opens only when an agent of the current project connects to the browser, instead of appearing in every project.
- **Slash commands send with one Enter.** In an agent's message bar, Enter (or a click) on a slash suggestion sends it right away; Tab still fills it in to add arguments.
- **Delegation wires use the nearest sides** of both cards instead of always parent-bottom to child-top.
- Settings search test accepts per-item rows (pre-existing failure since v1.0.17).
