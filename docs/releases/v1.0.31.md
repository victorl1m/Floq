# Release v1.0.31

## Storage Sense actually frees space

A real home had grown to 93 GB, mostly rebuildable data Storage Sense either did not know about or only reported.

- **Cleans by default.** With no mode chosen it now removes what is safe to remove (it used to only report). Choosing "Report only" in Settings > Plugins still works; an invalid saved value falls back to report-only.
- **New "Build output" category.** Folders marked with a CACHEDIR.TAG, the standard "safe to delete, regenerated on the next build" marker (Rust `target/` and other tools), inside project checkouts and workspaces, unused for 14 days (setting "Build output unused for (days)", 0 = never). In the measured home these were 20 GB.
- **Large scratchpads of ended sessions are removed.** They were too big to walk in one pass and were kept forever (1,746 of them, 17 GB). They are now judged by when their session was last active. Running and sleeping sessions are never touched.
