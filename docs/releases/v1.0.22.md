# Release v1.0.22

## Tasks & Automations

The Tasks screen is rebuilt and renamed **Tasks & Automations** (same acrylic look as Home, Settings and the canvas).

- **Project tasks.** Create tasks in a project with title, markdown description, priority, due date and an assigned agent. Board by status (To do, In progress, Blocked, Done) with drag and drop or a keyboard "Move" menu, a compact list view and quick add. Each task has a live activity timeline and comments.
- **Agents work on tasks.** A per-project switch (off by default) hands each "To do" task to the chosen agent (default: the project's orchestrator), waking it if needed. The agent moves the task along and comments with the new `floq task list | show | create | update | done | comment` commands (its own project only). A task is claimed atomically, so it is never handed out twice; if delivery fails (for example the provider is not signed in) it goes back to To do with a notification and a 15-minute retry backoff.
- **Date trigger ("Run on").** A task with a run date is handed to an agent only at that moment, e.g. only on the 19th at 09:00.
- **Automations.** On the same screen: run once, or repeat every N days, weeks, months or years, on chosen weekdays or a day of the month (31 = last day of shorter months), at a time in your timezone, with start date and an optional end date or run count. The editor shows the next 5 runs and a plain sentence ("Every month on day 19 at 09:00 (America/Sao_Paulo)"). Each run creates a task, handed to an agent when the project switch is on. Missed runs after downtime: run once or skip. "Run now" is available. Daylight-saving transitions are handled; one occurrence never runs twice, even with several runtimes.
- **Boards.** The existing organization boards are kept unchanged under a Boards tab.

## Fixes

- **Branch switcher shows remote branches.** It used to list only local branches, so a branch that existed only on GitHub never appeared. It now shows local branches immediately, fetches from the remote in the background (best effort; a failure just shows a short note) and adds remote-only branches with a "remote" badge; switching to one creates a local branch tracking it. Floq's own `floq/<agent>` worktree branches are no longer listed.
