# Release v1.0.39

## Fixes

- **Network isolation starts cleanly with unprivileged pasta.** At startup the runtime logged `netns.pasta_exited ... Couldn't open PID file /run/floq/netns/probe.pasta.pid: Permission denied` six times, then `pasta_gave_up` and `pasta_unprivileged_failed`, and fell back to running pasta as root. pasta drops to the `nobody` user and could not create its PID file in the root-owned directory. pasta already runs in the foreground, so the runtime now records its PID itself and no longer passes `--pid`; pasta keeps running unprivileged. The harmless "Can't run AVX2 build" notice is no longer logged as part of errors.
