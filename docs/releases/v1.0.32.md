# Release v1.0.32

## Tasks & Automations redesign

The screen now uses the same translucent material, spacing and type as Settings and Home, with fallbacks for Solid material, reduced transparency, forced colours and reduced motion.

- **Header:** page title, project dropdown (with All projects) and an "Agents work on tasks" card that explains what the switch does and lets you pick the receiving agent.
- **Quick add:** a composer like Home's; N focuses it from anywhere, Esc clears it.
- **Board:** translucent lanes with status dot and count; cards show title, description, Runs/Due chips (overdue in red), priority, origin and assignee; a Move to menu on hover or focus; drag shows the exact drop slot without shifting the layout.
- **List view:** grouped cards with status, chips, priority, assignee and Move menu.
- **Task panel:** reads like a document: large title, Write/Preview description, a metadata column (status, priority, assignee, Due, Run on), an activity timeline and Cmd/Ctrl+Enter to comment and save.
- **Automations:** one list showing each schedule sentence, the next run ("in 3 days"), the last status and run count, with switch, Run now and Edit/Delete.
- **Automation editor:** three sections; Repeat reads as a sentence ("Every 1 week at 09:00"); the next runs show as chips; catch-up is two explained choices.

Behaviour and server calls are unchanged.
