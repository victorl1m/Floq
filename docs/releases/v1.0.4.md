# Release v1.0.4

## Organizations

- **Edit an organization.** Settings > Organization > Identity lets owners and admins (and the owner of Personal) change the name, the image and, for team organizations, the URL name. The URL name is checked live ("checking", "available", "taken", "reserved", "invalid") before you can save. Members see the same fields read-only.
- **Organization images.** Choose, drop or paste an image. It is centre-cropped to a square, resized to 256 px and uploaded at once. It replaces the initials in the switcher, the account menu and settings.
- The Personal organization can be renamed too. The settings copy now points at the organization switcher at the top of the sidebar.

## Keychains removed (breaking)

- The canvas keychain feature is gone: the keychain node, dialog and cursor, the `/v1/keychains` routes and the agent-side routes behind them.
- **`floq secrets add` and `--keychain` no longer exist.** The per-user vault is unchanged (`floq-vault` skill, vault secrets injected as before).
- The keychain tables stay in the database, unused. No data is deleted.

## Terminal

- **+ in the Terminal view opens a plain shell** in one click, in the current project's workspace (or the scratch workspace with no project), with no provider, role or model choice.

## UI

- **Acrylic headers.** The Conversations and Changes sticky headers now tint from the pane colour, so they no longer read as an opaque black bar over the grey sidebar in dark mode.
- **Memory redesign.** A calmer Memory screen: header with status pill, one toolbar, richer list rows, a docked detail pane with a history timeline, and a graph on the canvas dot grid. Type colours follow the Floq palette.
- **Fixed "Invalid Date"** in Memory. Epoch seconds, numeric strings, placeholders and unparseable values now show a dash.

## Dependencies

- #7 GitHub Actions bumped, moving the workflows off Node 20.
- #8 `tokio-tungstenite` 0.30 in `src-tauri`.
- #9 runtime npm group (4 updates).
- #12 root npm group (18 updates), with **`pdfjs-dist` held at 5.4.149**. Version 6.x drops `isEvalSupported` and `PDFDocumentProxy.destroy`, which the file preview uses, and broke the Windows build.

## Database

- New migration `20261112100000_organization_images` adds the `organization_images` table. It runs on runtime start; no action needed.

## Tests

- `tsc --noEmit` clean, production build and runtime `tsc` succeed.
- Runtime unit tests 36/36, Playwright 152/152, `cargo test` 23/23.

This is a pre-release.
