# Release v1.0.29

## Fixes

- **Agents can keep talking across projects.** Loop protection counted every reply in a normal back-and-forth as one more forward, so after two round trips an orchestrator coordinating other projects had every message refused ("forwarded across projects 5 times in a row") for 10 minutes, even to an agent it had never talked to. A reply to the agent that last messaged you now keeps the hop count; only passing a message on to a third agent adds a hop. Real forwarding loops are still stopped at 4 hops.
- `floq decision request` "Too many decisions" now says the limits (3 pending per agent, 12 pending in total, 10 new per 10 minutes).

## Tests

- Runtime: crossProject (new back-and-forth case), messageDelivery, outbox. One older crossProject test still fails as before this release (it predates bracketed-paste delivery).

## Deployment

Runtime change: redeploy the runtime (or use Update runtime once the Docker socket is mounted).
