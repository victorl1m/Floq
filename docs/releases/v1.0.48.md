# Release v1.0.48

## New

- **WhatsApp is built into Floq (Settings > Integrations).** A new Integrations item in the Settings sidebar holds the WhatsApp card. It can be switched on only when a WhatsApp server (WAHA) is available: the built-in server beside Floq or an external one you connect (address and key are tested before saving). The card shows the connection, accounts, webhook health with Repair, settings and Open WhatsApp. Everything the WhatsApp plugin did is included: several accounts, media and voice notes, reactions, groups, contacts, history, the AI's access with approvals.
- **Built-in WhatsApp server (optional).** WAHA Core (Apache-2.0, official image, unmodified) can run as its own service in the runtime's compose file (profile `whatsapp`): internal network only, own volumes, media kept locally. Floq sets the address, the key and the webhook itself. Settings > Updates lists it as "WhatsApp server" with automatic updates (checked daily, only when WhatsApp is quiet and never during a QR login), health check and rollback.
- **History and contacts when you link.** WAHA keeps the history before the QR is shown; after the scan, chats, groups, contacts and messages are imported in the background with progress, cancel and "Import history again". Contacts stay in sync per account.
- **Receipts and webhooks repair themselves.** Floq creates and repairs its WAHA webhook (on create, attach, start and every 10 minutes); delivered/read ticks follow WhatsApp, also for messages Floq sent, and open chats refresh them.
- **WhatsApp in the island.** Incoming messages appear in the island with Reply, Mark read and Open chat; muted chats, the open chat and your own chat stay quiet; per-account on/off. The notification API is generic, so other plugins can use it.

## Changes

- The WhatsApp (WAHA) catalog plugin is deprecated. On update, Floq takes over its data, accounts, settings and keys in place and switches the plugin off. Deprecated plugins show a badge and are hidden from Browse for new installs.
- Inline ```code``` inside a WhatsApp message stays inline.

## Deployment

Desktop app updates itself. Runtime change: update the runtime. To use the built-in WhatsApp server, add `COMPOSE_PROFILES=whatsapp` and `FLOQ_WHATSAPP_API_KEY=<openssl rand -hex 32>` to `runtime/.env` (see README). If WAHA cannot reach Floq at its public address, set "Address WAHA uses to reach Floq" in Integrations > WhatsApp.
