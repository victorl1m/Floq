# Release v1.0.1

## Fixes

- **Claude Max usage in the footer.** The usage meter now reads Claude Max plans correctly.
  - Windows that the API returns as `null` are skipped instead of showing 0%.
  - The plan label reads Max 5x, Max 20x or Pro from the rate limit tier. The tier is stored at login, so accounts connected before this release show plain Max until you reconnect Claude in Settings.
  - The weekly OAuth apps window (`seven_day_oauth_apps`) and extra usage are parsed. Extra usage appears as its own window with the spend shown, such as "$12.30 of $50.00", and it does not drive the footer percent.
  - Expired sign-ins and tokens without the usage scope show a readable error. When usage cannot be loaded, the footer shows an explicit "usage unavailable" state instead of a blank meter.

## Tests

- Runtime tests for plan labels, Max, Pro and OAuth apps payloads, extra usage, error messages and the usage service (`runtime/test/usage.test.mts`).
- Playwright spec for the usage footer (`e2e/usage-footer.spec.ts`).

This is a pre-release.
