# Release v1.0.52

## Fixes

- **WhatsApp: "Unauthorized" with the built-in server on Dokploy.** The runtime reached the built-in WhatsApp server by the name `waha`, but on Dokploy the runtime also sits on the shared proxy network, where another stack's WAHA service answers to the same name. The runtime called that server with the built-in key and got 401. The built-in server now has the network alias `floq-whatsapp`, and the runtime uses `http://floq-whatsapp:3000`.

## Tests

- WhatsApp server config and compose (alias, address), server routes, plugin integration defaults; runtime build.
