# Floq v0.6.21

## Changes

- **Project icons.** Pick a project icon from a catalog of 233 icons in 10 categories, with search and a tint color. You can still use an uploaded or linked image. The image tab supports drag-and-drop, including drops from the file manager in the desktop app. It checks the image's size before decoding it, offers a square crop, and has a reset button. Icons are stored in the new `icon_name` and `icon_color` project columns.
- **Sidebar.** The hover **+** on a folder row now creates a subfolder and opens it for renaming. New project uses a project icon.
- **Canvas titlebar.** The Vault and New agent buttons are removed; Vault stays in the Secrets sidebar item. Wake all now sits in the middle of the tools in a rounded pill, and it also appears in the overflow menu.
- **Island.**
  - Request queue and draft fixes.
  - Reworked window motion for open, close, show, expand, collapse and switch.
  - A result stays visible 2.6 s after you hover, then fades out.
  - While a full-screen app (a game or a video) is in front, the island stays hidden. Focusing Floq brings it back, and a new request flashes Floq's taskbar button.
- **Plugins.** The plugin catalog is now explorer-style, with repo icons. Card text no longer overflows.
- **Agent communication.**
  - Long progress reports and questions from subagents reach the parent in full: a preview plus `floq inbox read`. They are no longer silently cut.
  - Text over the limit is rejected with a hint to use `--file`, and `floq progress` and `floq ask-parent` accept `--file`.
  - Every agent asks the user its open questions as Floq decisions.
  - `floq approval request --wait` works without `--timeout`.
- **Roles.** The orchestrator preset acts on its next step instead of recommending one.
- **Open-source preparation.**
  - Internal docs removed. Dev scripts moved to `scripts/dev/`, and the design docs moved to `docs/`.
  - Pinned image dependencies and SHA-pinned GitHub Actions.
  - Tighter desktop content security policy.

## Upgrade notes

- **Update the desktop app first.** First-run admin setup now needs a one-time setup token. The runtime prints it to its logs as "FLOQ SETUP TOKEN". An older desktop app cannot create the bootstrap admin against this runtime. Existing accounts are unaffected.
- **HTTPS for remote runtimes.** The desktop app now blocks plain `http://` runtime URLs except for localhost, 127.0.0.1 and [::1]. A self-hosted runtime reached over a LAN IP or hostname needs HTTPS; the login form explains this.
- **Runtime image.** Rebuild and deploy the runtime image. The `icon_name` and `icon_color` columns are added automatically and are safe to re-run. The runtime image now requires `POSTGRES_PASSWORD`.

## Verification and known limits

- **Builds:** the frontend build and the runtime typecheck pass.
- **Frontend tests:** 170/171 pass. The one failure is the unchanged malformed navigation-map preference test.
- **Runtime tests:** with the sandbox PTY stub, 785 pass, with 10 known port-request cancellations and 1 skip. The 1 failure is a sandbox test that needs a real PTY.
- **Rust:** not compiled on the verification host. This covers the `read_dropped_image` command and the island full-screen and motion changes. Windows installers are built by GitHub Actions.
- **Native behavior:** desktop drag-and-drop and the island behind full-screen apps still need checking on Windows.
