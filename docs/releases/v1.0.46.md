# Release v1.0.46

## Features

- **Update a plugin from its row in Settings > Plugins:** an installed plugin with a newer version in the catalog shows an "Update available" badge and an update button. One click updates it in place, with no restart; data, settings and secrets are kept, new migrations run, and an open plugin view reloads on the new version.
- **Plugins can send and receive larger files:** plugin api routes accept request bodies up to 8 MiB (was 64 KiB), and a plugin can read up to 24 MiB from the user's own configured service. The WAHA plugin 3.0.0 needs this to send photos, documents and voice notes.

## Tests

- Runtime: a plugin update keeps data, settings and the webhook token and runs new migrations; body and response caps.
- Playwright: plugin update row; WAHA plugin 3.0 specs on the built package (inbox, composer, bubbles, people, labels/status/calls, session and QR login).

## Deployment

Runtime change: update the runtime once (the Update button, or redeploy). The desktop app update brings the new Settings > Plugins row.
