# Floq v0.6.20

## Changes

- Center the canvas tools within the available titlebar slot. Project identity stays on the left; Wake all, Vault and New agent stay on the right. Tools fold into the existing menu earlier on narrow layouts to reserve room for the direct actions.
- Add a **Create as orchestrator** switch to New agent. It stays synchronized with the role picker and assigns the orchestrator role in the initial creation request, without creating a separate agent.
- Enable Claude automatic and idle compaction by default, with `CLAUDE_CODE_IDLE_COMPACT_MIN_TOKENS=150000`. Defaults are filled when a Claude session starts or resumes, including existing runtime users. Explicit user settings and environment overrides are preserved.

## Upgrade notes

The centered toolbar is part of the desktop update. Rebuild and deploy the runtime image for the bundled Claude settings defaults. Running Claude processes are not restarted automatically by this change.

On startup, Floq saves missing defaults into the user's Claude settings file; users can change those values afterward. Existing values remain unchanged. Idle compaction also requires Claude's one-hour prompt-cache lifetime, so sessions using the five-minute lifetime may not qualify.

Idle compaction requires an eligible, running Claude session and does not guarantee that a resume-cost warning will disappear after a long shutdown. This release does not add a resume dialog gate or a fresh-context handoff workflow.

## Verification and known limits

Frontend and runtime builds pass. Compaction regression tests pass 5/5. The full runtime suite with the existing sandbox PTY stub reports 764 passed, zero assertion failures, 10 known port-request cancellations and one skip.
