# Release v1.0.8

## Features

- **Single-tab Browser nodes.** Each Browser node on the canvas shows one page (right-click > New browser here, or the node's New browser button). Open as many nodes as you like; they share the one per-user profile, so a login works in all of them. Closing a node closes its page.
- **Agent and browser links.** Wire an agent to a Browser node like any other canvas link. A linked agent drives exactly that node's page through `floq-browser` and cannot open other tabs; you watch the same page live and can click in it. Many agents can share a node, and an agent drives one node at a time (linking elsewhere replaces the wire). The linked browser shows up in the agent's wired context. Unlinked agents never see node pages.
- **Full pointer input.** Hover, double click, right click, wheel, drag and modifier keys (Shift, Ctrl, Alt, Meta) reach the page. The node mirrors the page cursor, and coordinates stay correct under canvas zoom. The page viewport follows the node size.
- **Terminal resizer.** Terminal nodes get a resize handle.
- **Cloudflare hint bar.** When the title or URL of a page looks like a human check, the node shows a hint bar. You complete the challenge by hand in the live view and the profile keeps the clearance cookie. There is no stealth, no user agent change and no solver. Some sites block automation outright and cannot be completed by hand, for example g2.com answers 403.
- **Full Chromium in new headless mode.** The runtime image now ships the full Chromium 157 build (Playwright r1252) and runs it with `--headless=new` and its normal user agent, replacing the headless shell.

## Not built

- Per-node or per-project browser profiles (all nodes and agents share one profile).
- Locking a node against several agents driving it at once (last action wins).
- Stealth, fingerprint changes or challenge solvers, on purpose.

## Runtime image

- The browsers directory grows from about **280 MB to 412 MB** (full Chromium instead of the headless shell), and the image adds three apt libraries: `libcups2`, `libcairo2` and `libpango-1.0-0`. The install command, library list and build checks were verified by a dry run; the image was not built with Docker here, so measure the real size on the first build.
- Dokploy redeploys the runtime on push to main, so the larger image ships with this release. A new `browser_links` table is created on startup; the migration only adds a table.
- `docker build --build-arg FLOQ_BROWSER=0 runtime` still builds without the browser.

- Playwright: browser and canvas-select specs 34/34 (`browser-node`, `browser-pointer`, `browser-link`).
