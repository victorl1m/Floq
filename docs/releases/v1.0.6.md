# Release v1.0.6

## Fixes

- **Agents no longer vanish from a project's canvas.** The canvas hides agents tagged with another branch, and it compared branch names exactly. A project whose agents were tagged `Main` while the checkout reported `main` (or whose tags were stale) showed "has no agents yet" although it had agents. Branch names now compare case-insensitively, the lead and running agents are never hidden, and the filter can never empty the canvas. Affected projects are fixed on load; no data changes.
- **Pasting text vs images.** Every composer (agent message bar, canvas composer, Home) and the terminal now share one paste handler:
  - Text only: pasted as text, no image lookup.
  - An image copied together with its file name, URL or HTML: attached as an image.
  - An image with real text: both.
  - Nothing usable in the paste event: a silent fallback to the native clipboard image (PNG/DIB on Windows).
  - The "no image found" error no longer appears on normal text pastes.

## Tests

- `e2e/branch-hide.unit.mts` (3) and `e2e/paste.spec.ts` (7) are new; the Home and paste specs pass 24/24.
- `tsc --noEmit` clean and the production build succeeds.

This is a pre-release.
