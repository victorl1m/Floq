# Release v1.0.21

## Features

- **Automatic updates.** Floq checks for a new version 30 s after start and every 6 hours, downloads it in the background and offers "Restart now / Later" (Later offers it again on the next launch). The installer runs in passive mode: a progress bar, no wizard. Settings › Advanced has "Check for updates", an on/off switch and the current version.
  - Secure: every update is verified against the minisign public key built into the app before it installs; downloads come only from github.com over HTTPS; never an older version. The update signature is made over the final code-signed installer.
  - Feed: `releases/download/updater/latest.json`, replaced by each `v*` build only after its installer is public. See `docs/updater.md`.
  - **This is the first version with the updater:** install v1.0.21 by hand once; later versions arrive automatically.
- **Storage Sense** (bundled plugin). Cleans up what agents leave behind: worktrees and `floq/<agent>` branches of dismissed agents (only when clean and their work is already in the base branch, cherry-picks included; otherwise kept and reported as "has unsaved work"), old scratchpads and task output, old attachments and Floq temp files. Never touches Artifacts, transcripts, checkpoints, the vault, project checkouts, symlink targets or anything of a live or sleeping agent. Runs daily, when free space drops low, or on "Run now"; **report-only by default** (shows what it would remove) until you turn cleanup on. Design: `storage-sense-design.md` (Floq Artifacts).

## Fixes

- **Faster install, upgrade and uninstall.** The installer stops Floq only when it is running and waits for it to exit (at most 3 s) instead of always sleeping; an upgrade no longer stops it twice; the WebView2 bootstrapper is embedded so it is never downloaded when WebView2 is present. Expected about 1 s faster for install/uninstall and about 2 s per upgrade (the uninstall-side saving starts from the second upgrade, because the first one runs the old uninstaller). See `docs/installer-performance.md`.
- Stale plugin-host test updated for the current right sidebar tabs (pre-existing failure).
