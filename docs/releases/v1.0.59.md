# Release v1.0.59

## WhatsApp

- **Deleted messages are recoverable.** The bubble says "This message was deleted" (or "You deleted this message"); "Show original" reveals the text, quote and media Floq kept, with the time of deletion. "Original not received" when Floq never had it.
- **Edited messages** show "Edited" next to the time; clicking it opens the edit history (original, each edit, current, with times).
- **Stickers** render like WhatsApp: no bubble, 160 px, click to enlarge (Lottie stickers show a still).
- **Export chats:** "Export chat" in the chat menu and contact/group info, "Export all chats" in the account menu. WhatsApp's own .txt format in your locale and time zone, a zip with media, optional HTML or Markdown; deleted and edited messages marked; missing media listed.
- **Read receipts are manual.** Opening a chat no longer sends blue ticks. A "Mark as read" button sends them; replying sends them first, like WhatsApp. A per-account setting "Send read receipts automatically" (off by default) restores the old behaviour.
- **The open chat updates live**, including messages found by the chat sync or announced under a contact's other address (@lid / phone).
- **The emoji picker opens at once** (it now draws the visible emojis first).

## Browser

- **Each project has its own pages.** A project's Browser nodes and agents never see, attach to or adopt another project's page; pop-ups stay in their project. Logins (cookies) stay shared across projects, as designed.

## App

- **The island no longer freezes.** One failed update (sleep, screen off, RDP) used to disable it for good, leaving stuck buttons while dialogs appeared in the main window; it now retries and re-syncs on focus.

## Runtime

- **Server time zone:** optional `FLOQ_TIMEZONE`, then `TZ`, then the server's clock. Used for agents' clocks, automation times, limit-reset parsing and WhatsApp export; shown in Settings > Runtime.

## Tests

- WhatsApp runtime 327/327; fallback, time zone and browser service 106/106; Playwright 50/50 (waha-live, waha-edits, waha-export, island-bridge, browser-projects, waha-emoji-perf, native-menu, network-footer); frontend and runtime type checks.

## Deployment

Runtime and desktop change: Dokploy redeploys the runtime on push; the desktop app updates itself. WhatsApp migration 009 (read receipts) runs on start.
