# Release v1.0.30

## Changes

- **Storage Sense moved to the footer.** It is no longer a sidebar item: a button right of memory usage shows free space (and a red dot when something needs attention) and opens the last report with Preview and Clean now. Hidden when the plugin is off.
- **Storage Sense notifications are opt-in.** New setting in Settings > Plugins > Storage Sense: "Notify me after cleanups", off by default.

## Tests

- Frontend typecheck; runtime build; Storage Sense plan, schedule and service tests (21).

## Deployment

The footer arrives with the desktop update. Removing the sidebar item and the notification switch need the runtime redeployed; until then the old sidebar entry stays and notifications keep going.
