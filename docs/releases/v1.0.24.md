# Release v1.0.24

## Features

- **Agents can create vault secrets.** `floq secrets add NAME [--description TEXT] [--generate [BYTES]]` saves a secret in your Floq vault, for example an API key an agent just created in a dashboard.
  - The value is read from stdin only, never from the command line (where other processes and shell history could see it).
  - `--generate` creates a random value inside the vault (16-256 bytes, default 32) that the agent never sees, for passwords and tokens.
  - Create-only: an existing name is refused; only you can change or delete secrets, in Floq › Vault.
  - Agent-created secrets are tool-only: agents can use them with `floq-vault run`, but cannot read them back.
  - You get a security notification for every secret an agent creates.

- **Claude Code experimental code mode on by default.** Claude sessions start with `CLAUDE_CODE_EXPERIMENTAL_CODE_MODE=1` (set by the runtime; `FLOQ_CLAUDE_CODE_MODE=0` turns it off for the whole runtime).
- **Claude Code updated to 2.1.328** in the runtime image (was 2.1.319).
- **App updates moved to Settings › About** (check for updates, restart into a downloaded version, automatic updates), out of Advanced.
- **Tasks & Automations use the acrylic look** of the rest of the app: board columns, the header bar, automation rows and editor panels sit on the translucent material instead of opaque fills.

## Tests

- App: 104 unit tests and `tsc --noEmit` clean. Runtime: providers, CLI providers and toolkit suites (43) pass; build clean.
- Runtime: the toolkit suite (20) covers stdin-only values, refused argv values and bad names, create-only conflicts, tool-only storage, encrypted at rest, and generated values never printed.

## Deployment

Runtime release: rebuild and redeploy the runtime image (the agent CLI and route ship with it). The desktop app updates itself.
